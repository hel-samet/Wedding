# Wedding Invitation

A responsive Khmer wedding invitation website built with HTML, CSS, JavaScript, Vite, and GSAP.

## Development

```sh
npm.cmd install
npm.cmd run dev
```

## Production build

```sh
npm.cmd run build
npm.cmd run preview
```

On macOS or Linux, replace `npm.cmd` with `npm`.

Scroll-triggered entrances and the hero sequence use GSAP. Background music is synthesized in the browser and starts only after the visitor presses the music button.
